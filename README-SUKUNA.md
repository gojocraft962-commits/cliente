# Sukuna Client
Base de desenvolvimento para Minecraft Java 1.21.11, Fabric e Java 21.

## Categorias
Combat, Movement, Rendering, Player, World, Miscellaneous e HUD.

## Estado atual
Inclui estrutura Fabric e catálogo dos módulos identificados na imagem. A maioria dos módulos está registada como placeholder: ainda não é um cliente final jogável. Faltam o ClickGUI visual, persistência das configurações, keybinds e implementação/testes individuais dos módulos.

Módulos destinados a crashar servidores, enviar spam, abusar de pacotes ou perturbar terceiros não serão implementados.

## Compilar
Com JDK 21 e Gradle: `gradle build`. O JAR será criado em `build/libs/`.

Documentação: https://docs.fabricmc.net/
